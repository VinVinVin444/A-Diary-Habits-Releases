# A-Diary-Habits

把习惯打卡、日记记录、话题标签与每日复盘集中在一个 Obsidian 主页中的个人记录插件。

## 主要功能

- 按日视图或周视图记录习惯次数与备注，并提供习惯管理和统计。
- 创建、查看和编辑日记，支持多标签、时间轴、图片粘贴与图片查看。
- 按月份、年份和标签检索历史记录，并管理话题标签。
- 自动汇总当日习惯、日志、标签、图片、任务和进度数据，完成每日复盘。
- 支持亮色、深色和小岛主题，并适配桌面端与移动端布局。
- 使用 Vault 内的 Markdown 文件保存主要业务数据，便于备份和多设备同步。

## 数据与备份

习惯配置、标签和每日日记等主要数据保存在当前 Vault 的 `A_DiaryHabits_Data` 目录；插件设置和离线许可证保存在当前 Vault 的插件配置数据中。

建议备份整个 Vault，或至少备份 `A_DiaryHabits_Data` 与插件配置目录。卸载插件不会主动删除已保存的 Markdown 日记和附件。
